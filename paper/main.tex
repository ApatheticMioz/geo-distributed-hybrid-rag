\title{Take the Hint: Speculative Prefill Acceleration for Geo-Distributed Hybrid RAG}

\author{
  \IEEEauthorblockN{Muhammad Abdullah Ali, Muhammad Abdullah Aamir, and Adil Majeed\IEEEauthorrefmark{1}}
  \IEEEauthorblockA{Department of Data Science, FAST-NUCES, Islamabad, Pakistan\\
  \IEEEauthorrefmark{1}adil.majeed@nu.edu.pk}

\maketitle

\begin{abstract}
Deploying hybrid Retrieval-Augmented Generation (RAG) across geographically distributed edge--cloud fleets introduces fundamental stage placement trade-offs. While dense neural encoders and large language models demand high-end GPU capacity, lexical sparse search is CPU-bound and document hydration is an $O(1)$ disk lookup. Through physical multi-tier testbed measurements across wide-area network (WAN) regimes, we show that wide-area transit delay is decoupled from payload bulk when maintaining identifier-sized boundaries. Instead, KV-cache state dominates latency variance: cold-prefix time-to-first-token (TTFT) reaches $2.8$--$3.2\times$ warm steady-state latency, leaving cloud generation GPUs idle while awaiting regional neural retrieval. Exploiting this retrieval-prefill asymmetry, we introduce SPHP (Speculative Progressive Hydration \& Prefill), an asynchronous pipeline protocol for geo-distributed three-tier fleets: Edge Ingress (Node~C), Regional Gateway (Node~B), and Central Cloud Host (Node~A). SPHP streams an early provisional sparse hint directly from Edge Ingress to the Cloud Host, overlapping cloud transformer prefill with in-flight regional dense retrieval and rank fusion before committing at a formal verification barrier. Across physical three-tier testbeds, SPHP achieves a 90.0\% speculation hit rate, cutting cold-prefix TTFT by 17\%--28\% across WAN regimes without generative divergence, while flattening Link~B sensitivity to $0.153$~ms/ms. We cross-validate a closed-form placement cost model and demonstrate empirical robustness across live unshaped public internet routes, multi-leg packet loss stress matrices, and automated edge failovers.
\end{abstract}

\section{Introduction}
\label{sec:intro}
Retrieval-Augmented Generation (RAG) grounds large language models (LLMs) in external factual corpora, mitigating hallucinations and expanding parametric knowledge \cite{lewis2020rag,guu2020realm,borgeaud2022retro,gao2024ragsurvey}. Modern production pipelines increasingly adopt \emph{hybrid} architectures combining lexical sparse retrieval (BM25 \cite{robertson1994bm25}) for exact keyword matching, dense neural representations (BGE-M3 \cite{chen2024bge}, DPR \cite{karpukhin2020dpr}) for semantic generalization, reciprocal-rank fusion (RRF \cite{cormack2009rrf}), passage hydration, and autoregressive generation under optimized serving engines like vLLM \cite{kwon2023vllm}.

Deploying hybrid RAG across geo-distributed edge--cloud fleets exposes a fundamental \emph{placement dilemma}. Constituent pipeline stages exhibit radically divergent computational and memory footprints. Dense embedding computation and LLM generation require specialized GPU accelerators with substantial VRAM, whereas sparse inverted-index traversal is memory-bandwidth- and CPU-bound, and document hydration is an $O(1)$ key-value lookup. Although deep neural network (DNN) layer partitioning \cite{kang2017neurosurgeon,banitalebi2021autosplit,teerapittayanon2017ddnn} and LLM phase disaggregation (prefill vs.\ decode) \cite{patel2024splitwise,zhong2024distserve,janus2025,qin2025mooncake,mei2025helix} have been investigated for monolithic models, the systems principles governing multi-stage hybrid RAG pipelines partitioned across heterogeneous, wide-area topologies remain uncharacterized.

Through physical multi-tier testbed measurements over the 8.84M-passage MS~MARCO benchmark \cite{bajaj2018msmarco}, we uncover two governing systems properties:
\begin{enumerate}
    \item \textit{Decoupling of WAN Delay from Payload Bulk}: When wide-area boundaries transmit compact document identifiers ($104$--$144$~bytes) rather than hydrated text ($\approx$6~KB), time-to-first-token (TTFT) increases by only $\approx$0.95~ms per millisecond of round-trip time (RTT). The network transit delay is effectively linear and predictable.
    \item \textit{KV-Cache State Dominates Latency Variance}: In contrast to network delay, KV-cache state dominates TTFT variance. Cold-prefix TTFT reaches $2.8$--$3.2\times$ warm steady-state latency ($1{,}656$--$1{,}720$~ms cold vs.\ $510$--$588$~ms warm), largely driven by transformer prefill and GPU page-table allocation. Serializing regional dense retrieval before cloud prefill leaves cloud GPUs idle while awaiting regional candidate sets.
\end{enumerate}

To exploit this retrieval-prefill asymmetry, we introduce \textbf{SPHP} (Speculative Progressive Hydration \& Prefill). SPHP pipelines edge sparse retrieval and cloud generation. Upon completing BM25 search on the edge tier (Node~C), SPHP streams an early provisional sparse hint ($\mathcal{H}$, $104$~bytes) directly to the cloud generator (Node~A), initiating speculative prefill in cloud VRAM concurrently with in-flight dense neural embedding and fusion on the regional gateway (Node~B). When the verified ranking ($\mathcal{F}$, $144$~bytes) arrives, Node~A evaluates a formal set-overlap verification barrier ($\text{Overlap} \ge \theta$). On a hit ($h=0.900$), the resident KV-cache commits without stall, cutting cold TTFT by 17\%--28\% while preserving generative fidelity.

This paper makes four primary contributions:
\begin{itemize}
    \item \textit{Empirical Critical-Path Characterization}: We provide the first multi-tier physical characterization of geo-distributed hybrid RAG, quantifying the retrieval-prefill asymmetry and the dominance of KV-cache state over wide-area transit delay.
    \item \textit{SPHP Protocol}: We design and implement SPHP, an asynchronous speculative pipeline protocol that overlaps cloud prefill with regional retrieval across wide-area boundaries.
    \item \textit{Analytical Placement Cost Model}: We formulate and cross-validate a closed-form placement cost model (leave-one-tier-out MAPE 2.15\% cold / 4.13\% warm), demonstrating that speculative split placement is globally optimal across wide-area regimes.
    \item \textit{Physical Testbed Evaluation \& Robustness}: Across physical three-node tiering (CM-2), unshaped public internet routes (CM-4), a 27-cell asymmetric packet loss stress matrix (CM-5), and automated edge failovers, we demonstrate that SPHP maintains uniform acceleration and high speculation hit rates ($81.3\%$--$86.9\%$).
\end{itemize}

\section{Related Work}
\label{sec:related}

\subsection{Hybrid RAG \& Systems Tradeoffs}
Retrieval-Augmented Generation bridges parametric memorization and external dynamic knowledge \cite{lewis2020rag,guu2020realm,borgeaud2022retro,gao2024ragsurvey}. Hybrid retrieval pairs exact keyword precision from inverted indices (BM25 \cite{robertson1994bm25}) with semantic dense vector search (DPR \cite{karpukhin2020dpr}, BGE-M3 \cite{chen2024bge}) through reciprocal-rank fusion (RRF \cite{cormack2009rrf}). Shen \emph{et al.}~\cite{shen2024ragtradeoffs} analyzed systems trade-offs in monolithic RAG serving on single instances, demonstrating that retrieval latency can dominate execution. However, monolithic studies do not consider network cuts, geo-distribution, or disaggregated multi-tier stage placement.

\subsection{Speculative Execution in Inference}
Speculative decoding accelerates autoregressive generation by drafting candidate tokens on a smaller auxiliary model and verifying them in parallel on the target LLM \cite{leviathan2023speculative,chen2023speculative}. In distributed settings, \emph{Speculation at a Distance} \cite{lyu2026speculation} showed that wide-area round-trip times severely undermine token-level speculation due to round-trip latency amplification. SPHP operates on an orthogonal systems dimension: rather than speculating over output tokens across the network, SPHP speculates over the \emph{pipeline schedule} on the generation host. While Speculative RAG \cite{speculativerag2025} and Omnia \cite{omnia2025} explore speculative drafting across document subsets without pipeline reconciliation, SPHP leverages an early provisional sparse hint to overlap prefill with dense retrieval, using set overlap as a formal verification barrier.

\subsection{Edge--Cloud Serving \& Placement Models}
Partitioning neural network execution between edge and cloud has been studied for DNN layer partitioning (Neurosurgeon \cite{kang2017neurosurgeon}, Auto-Split \cite{banitalebi2021autosplit}, DDNN \cite{teerapittayanon2017ddnn}) and LLM phase disaggregation (Splitwise \cite{patel2024splitwise}, DistServe \cite{zhong2024distserve}, Janus \cite{janus2025}, Mooncake \cite{qin2025mooncake}, Helix \cite{mei2025helix}). These systems separate prefill and decode instances over datacenter interconnects. In contrast, our work addresses multi-stage hybrid RAG pipelines where constituent stages (sparse traversal, dense neural encoding, rank fusion, document hydration, autoregressive decoding) possess radically divergent compute, memory, and storage footprints across wide-area network boundaries.

\section{System Architecture \& Topologies}
\label{sec:architecture}

\subsection{Multi-Tier Physical Hierarchy}
Our physical testbed couples heterogeneous machines across wide-area networks over WireGuard tunnels \cite{donenfeld2017wireguard} (Figure~\ref{fig:arch}):
\begin{itemize}
    \item \textit{Edge Ingress Tier (Node~C)}: Hosted on an Intel Core i5 workstation (16\,GB RAM). Node~C terminates client HTTP connections, parses queries, executes Tantivy BM25 sparse lexical search over the 8.84M-passage MS~MARCO index \cite{bajaj2018msmarco}, and streams response tokens back to users via Server-Sent Events (SSE).
    \item \textit{Regional Neural Gateway (Node~B)}: Hosted on an Intel Core i7-10750H machine equipped with an NVIDIA GTX~1660~Ti GPU (6\,GB VRAM) and 32\,GB RAM. Node~B computes 1024-dimensional BGE-M3 dense embeddings \cite{chen2024bge}, queries an HNSW vector index in Qdrant, and executes reciprocal-rank fusion ($k=60$) \cite{cormack2009rrf}.
    \item \textit{Central Cloud Host (Node~A)}: Featuring an AMD Ryzen 7 7700 processor and an NVIDIA GeForce RTX~3090 GPU (24\,GB VRAM). Node~A serves the Qwen3.8-27B generator \cite{qwen3technicalreport} under vLLM \cite{kwon2023vllm} with AutoRound W4A16 quantization \cite{autoround2024}. Node~A maintains an indexed SQLite passage store for $O(1)$ hydration, evaluates candidate overlap at the verification barrier, and executes prefill and decoding.
\end{itemize}

\subsection{Placement Topology Taxonomy}
We define candidate placement topologies based on where wide-area boundaries bisect the pipeline (Table~\ref{tab:topologies}). P0 colocates all stages on the cloud host, whereas P1 routes ingress through Node~C but executes all retrieval and generation in the cloud. In the primary physical three-node topology (P2), lightweight sparse search executes on Node~C, while memory-intensive dense retrieval executes on Node~B. To minimize WAN bandwidth, only top-$k$ document identifiers ($104$--$144$~bytes) cross the network to Node~A for hydration and generation.

The speculative protocol (P2-SPHP) enables Node~C to dispatch an early provisional sparse hint ($104$~bytes for top-5 IDs) directly to Node~A over Link~C, initiating masked prefill in cloud VRAM concurrently with neural retrieval on Node~B. When Node~C and Node~B are co-located at the same facility, the topology collapses to the consolidated two-node control baseline (P2-Consol), which we evaluate to isolate internal stage mechanics and parameterize our analytical cost model. Finally, P3 evaluates shifting document hydration to the edge, transmitting hydrated raw text ($\approx$6\,KB) across the WAN.

\subsection{Network Control Protocol}
To emulate wide-area links faithfully, we apply Linux \texttt{netem} \cite{netem2024} bidirectionally: outbound packets are delayed by $\mathrm{rtt}/2$ via egress qdiscs, while inbound packets are redirected to intermediate functional block devices (\texttt{ifb}) and delayed by $\mathrm{rtt}/2$. We evaluate Link~B and Link~C across four delay tiers: 0~ms (LAN control), 15~ms (metro), 40~ms (regional), and 80~ms (transcontinental) at 100~Mbps bandwidth, complemented by unshaped public internet routes (CM-4) and a 27-cell asymmetric loss stress matrix (CM-5). Emulation fidelity is verified before and after every run against a $\pm$30\% RTT ping gate and a $\pm$0.05\,pp loss readback gate.

\subsection{Stage Latency Decomposition \& Retrieval Asymmetry}
Table~\ref{tab:latency} details per-stage latencies across cache states and network tiers. In the warm steady-state, sparse lexical search completes in 68--89~ms, whereas dense neural search requires 111--118~ms, exhibiting a consistent $1.3$--$1.6\times$ asymmetry. In the cold-prefix state, sparse search requires 576--640~ms (dominated by OS page faults across the 8.84M inverted index), while dense encoding and index traversal require 1{,}029--1{,}130~ms ($\approx$1.8$\times$).

Crucially, the parallel retrieval barrier ($\max(\Tsparse, \Tdense)$) consumes only 111--131~ms of the warm TTFT budget ($510$--$588$~ms). The \emph{prefill residual}---encompassing passage hydration, tokenization, transformer context prefill, and engine queueing---demands 392--464~ms in the warm state. Consequently, optimizing network transit cannot yield substantial savings; latency acceleration must target overlapping the prefill residual.

\subsection{Dominance of KV-Cache State over WAN Latency}
The latency disparity between cache states in Table~\ref{tab:latency} overshadows network variations. Cold TTFT ($1{,}656.8$--$1{,}720.0$~ms) is $2.8$--$3.2\times$ warm TTFT ($510.0$--$587.6$~ms) across all evaluated tiers. Across the full 0 to 80~ms RTT sweep, warm TTFT increases by only 77.6~ms (slope $\approx$0.95~ms/ms), precisely reflecting a single WAN crossing for identifier payloads, while cold TTFT remains statistically flat across network tiers (Figure~\ref{fig:ttft}).

Autoregressive decode throughput ($\Rdecode$) is calculated as:
\begin{equation}
    \Rdecode = \frac{N - 1}{T_{\mathrm{decode}}} = \frac{N - 1}{(t_{\mathrm{end}} - t_{\mathrm{first\_token}}) / 1000.0},
    \label{eq:rdecode}
\end{equation}
where $N$ is emitted tokens, $t_{\mathrm{first\_token}}$ is client arrival of the initial streaming token (marking TTFT completion), and $t_{\mathrm{end}}$ is stream termination. Equation~\eqref{eq:rdecode} strictly isolates memory-bandwidth-bound autoregressive decoding from prompt prefill. As shown in Table~\ref{tab:latency}, $\Rdecode$ remains constant at $35.2$--$35.5$~tok/s across all network regimes, confirming that wide-area transit bottlenecks only the delivery of the initial token; once token emission commences, delivery proceeds at line rate without streaming stalls.

\label{sec:sphp}

\subsection{Protocol Specification}
SPHP pipelines retrieval and generation across the three-tier hierarchy (Figure~\ref{fig:sphp}). Rather than serializing dense retrieval and fusion prior to cloud execution, SPHP exploits the temporal head start of edge sparse traversal through an asynchronous protocol:
\begin{enumerate}
    \item \textit{Provisional Hint Dispatch}: Upon completing BM25 search at time $\Tsparse$, Node~C immediately streams a provisional hint consisting of top-5 sparse passage identifiers ($\mathcal{H}$, $104$~bytes) over Link~C to Node~A.
    \item \textit{Speculative Prefill}: While BGE-M3 dense encoding and HNSW search proceed concurrently on Node~B, Node~A hydrates provisional passages from its local SQLite store and initiates speculative masked prefill $\hat{P}$ in VRAM. Candidate tokens generated during this window remain buffered internally and are strictly masked from the client SSE stream.
    \item \textit{Verification Barrier}: When the verified ranking ($\mathcal{F}$, $144$~bytes for top-10 IDs) arrives from Node~B at time $t_f = \Tdense + \Tfusion + \Twan$, Node~A evaluates candidate agreement:
    \begin{equation}
        \text{Overlap}(\mathcal{H}, \mathcal{F}) = \frac{|\mathcal{H} \cap \mathcal{F}|}{|\mathcal{H}|}.
    \end{equation}
\end{enumerate}
If $\text{Overlap}(\mathcal{H}, \mathcal{F}) \ge \theta$ with $\theta = 0.5$, speculation hits: $\hat{P}$ is committed, the provisional KV-cache is preserved, and autoregressive decoding commences without stall. On a speculation miss, $\hat{P}$ is discarded, paying an abort penalty $\Tmiss$ ($124.5$~ms warm, $1{,}076.6$~ms cold), and full prefill executes over the verified ranking $\mathcal{F}$.

\subsection{Semantic Verification \& Guardrailing}
Dense retrieval serves as an \emph{asynchronous semantic guardrail}. While sparse retrieval provides rapid passage identification ($68$--$89$~ms), it lacks semantic context when queries exhibit vocabulary mismatch. On queries where lexical matching diverges from semantic relevance, the candidate sets disagree ($|\mathcal{H} \cap \mathcal{F}| / |\mathcal{H}| < \theta$), triggering an automatic abort and payment of $\Tmiss$ to execute standard hybrid prefill on $\mathcal{F}$. SPHP thus achieves sparse latency profiles on concordant queries while maintaining full hybrid recall guarantees across the query distribution.

\subsection{Acceleration and Generative Fidelity}
Across evaluated regimes, SPHP reduces cold TTFT by 23.7\%--27.6\% ($-24.1\%$ at 0~ms, $-27.6\%$ at 15~ms, $-23.7\%$ at 40~ms, and $-25.5\%$ at 80~ms RTT). All four one-sided permutation tests clear the Holm-FWER significance threshold ($p \le 0.0008$, Cohen's $d = -1.29$ to $-1.57$). In absolute terms at 0~ms RTT, mean cold TTFT drops from $1{,}656.8$~ms to $1{,}258.4$~ms ($-398.4$~ms). Across the benchmark, the empirical speculation hit rate reaches $h = 0.900$ (95\% CI $[0.883, 0.914]$), with a mean candidate set overlap of 0.636.

Because committed hit-path responses are generated from provisional sparse context, we evaluate answer drift across 200 seeded dev queries against baseline P2. Re-generating responses from identical fused contexts under baseline P2 establishes an empirical upper bound of token-F1 $= 0.586$ (Exact Match 0.121) due to decode sampling stochasticity. Hit-path SPHP responses achieve a token-F1 agreement of 0.422 (Exact Match 0.042) against baseline. Qualitative inspection confirms that divergence stems from minor lexical rephrasings rather than factual degradation.

\section{Analytical Placement Cost Model}
\label{sec:costmodel}

\subsection{Closed-Form Placement Formulation}
We formulate an analytical cost model predicting TTFT as a function of payload size $p$, round-trip time $\mathrm{rtt}$, and link bandwidth $\mathrm{bw}$ (Mbps):
\begin{equation}
\Twan(p, \mathrm{rtt}, \mathrm{bw}) = \frac{\mathrm{rtt}}{2} + \frac{8\,p}{\mathrm{bw} \times 10^6} \times 10^3\ \text{ms}.
\end{equation}
Payload sizes are $p_{\mathrm{id}} = 144$~B (top-10 IDs), $p_{\mathrm{hint}} = 104$~B (top-5 hint), and $p_{\mathrm{text}} = 6{,}064$~B (hydrated text). Letting $T_{\mathrm{ret}} = \max(\Tsparse, \Tdense)$, the expected TTFT equations for non-speculative baselines are:
\begin{align}
\Tttft^{(0)} &= T_{\mathrm{ret}} + \Tfusion + \Thydrate + \Tprefill, \label{eq:p0}\\
\Tttft^{(2)} &= \Tttft^{(0)} + \Twan(p_{\mathrm{id}}), \label{eq:p2}\\
\Tttft^{(3)} &= \Tttft^{(0)} + \Twan(p_{\mathrm{text}}), \label{eq:p3}
\end{align}
while the speculative SPHP placement cost is modeled as:
\begin{equation}
\begin{split}
\Tttft^{(2,\mathrm{SPHP})} &= h \max(t_f, t_p) \\
&\quad + (1-h)(\Tttft^{(2)} + \Tmiss) - C_{\mathrm{c}},
\end{split}
\label{eq:sphp_cost}
\end{equation}
where $t_s = \Tsparse + \Twan(p_{\mathrm{hint}}) + \Thydrate$, $t_p = t_s + \Tprefill$, and $t_f = \Tdense + \Tfusion + \Twan(p_{\mathrm{id}})$. The term $C_{\mathrm{c}}$ ($64$~ms cold, $0$ warm) represents the \emph{overlapped memory allocation credit}: on cold engines, launching provisional prefill absorbs GPU page-table allocation and CUDA graph instantiation during the retrieval head-start window ($\Delta t = \Tdense - \Tsparse \approx 489$~ms), which baseline P2 serializes on the critical path.

\subsection{Validation \& Uniform Optimality}
Stage latency parameters are empirically fitted from baseline medians across query executions: under warm steady-state, $\Tsparse = 79.2$~ms, $\Tdense = 114.0$~ms, and $\Tprefill = 423.6$~ms; under cold initialization, $\Tsparse = 603.2$~ms, $\Tdense = 1{,}091.7$~ms, and $\Tprefill = 568.1$~ms. Decode throughput is $\Rdecode = 35.3$~tok/s. Leave-one-tier-out cross-validation across all four evaluated network tiers ($0$, $15$, $40$, and $80$~ms RTT) yields held-out mean absolute percentage errors (MAPE) of 2.15\% cold / 4.13\% warm for P2, and 6.42\% cold / 4.37\% warm for SPHP.

Sweeping the validated cost model across the operating domain (RTT $\in [0, 200]$~ms, bandwidth $\in [10, 1000]$~Mbps) proves that speculative split placement (P2-SPHP) is uniformly optimal across all 35 evaluated cells. The warm-state latency advantage (2.8\%--3.4\%) and cold-prefix advantage (23.2\%) remain strictly invariant across network RTT because identifier payloads serialize in under 0.1~ms.

\subsection{Physical Three-Node Tiering (CM-2)}
We evaluate the physical three-tier hierarchy enrolling Node~C as edge sparse tier, Node~B as regional neural gateway, and Node~A as cloud host across three WAN regimes ($B \in \{15, 40, 80\}$~ms, $C{=}15$~ms; $N=240$ queries/arm; Table~\ref{tab:generalization}a). \subsection{Live Unshaped Public Internet Validation (CM-4)}
To confirm that synthetic \texttt{netem} reflects authentic network conditions, we evaluated unshaped public internet routes ($N=50$ queries/arm, \texttt{netem} disabled). \subsection{Asymmetric Loss Stress Matrix \& Resilience (CM-5)}

Under concurrent 2\% loss on both Link~B and Link~C at $B=80$~ms, SPHP achieved a 34.54\% TTFT reduction with 100\% hit rate.

We assessed fault tolerance by injecting 45~s service terminations into active 365-request streaming sequences. In the two-node edge failure scenario (killing Node~B), exactly two requests exceeded the 30~s timeout before service restored with a Time-to-Recovery (TTR) of 86.5~s (including process re-initialization and memory warming). Post-recovery latency settled within 1.4\% of baseline (median 1.86~s vs.\ 1.83~s) with zero errors across the remaining 295 requests. In the three-node failure scenario (terminating Node~C), edge failover yielded a TTR of 64.27~s, resuming execution with zero errors at identical latency (p50 2.07~s pre- and post-fault).

\section{Discussion \& Threats to Validity}
\label{sec:discussion}

\subsection{Systems Design Implications}
Our findings contradict the intuition that WAN stage placement in distributed RAG is governed by network transmission delay. When identifier-sized boundaries are maintained across the network cut, WAN RTT is a second-order factor, whereas KV-cache state swings TTFT by up to $3.2\times$. Distributed RAG systems engineering should prioritize cache prefix warming and speculative prefill scheduling over wide-area link micro-optimizations.

\subsection{Client-Observed Goodput vs.\ Engine Metrics}
Distinguishing client-observed goodput from server-internal engine throughput is critical in geo-distributed evaluation. Single-node deployments frequently rely on engine-internal metrics (e.g., vLLM internal counters). In a distributed multi-tier architecture, internal counters track only GPU CUDA forward passes on the local instance, remaining blind to operating system socket buffers, WireGuard encapsulation, MTU fragmentation, and HTTP SSE stream framing at the edge gateway. Measuring client-observed goodput via Equation~\eqref{eq:rdecode} captures true end-to-end user delivery, demonstrating that decode throughput remains invariant at $35.2$--$35.5$~tok/s across all evaluated regimes.

\subsection{Limitations \& Artifacts}
Speculation commitment is governed by set overlap $\text{Overlap}(\mathcal{H}, \mathcal{F}) \ge \theta$. While static $\theta = 0.5$ delivers robust acceleration ($h = 0.900$), query ambiguity benefits from adaptive calibration using BM25 score dispersion $\Delta_{\mathrm{BM25}} = s_{\mathrm{BM25}}(d_1) - s_{\mathrm{BM25}}(d_{k_h})$: steep dispersion permits aggressive speculation ($\theta \to 0.4$), while flat dispersion warrants conservative verification ($\theta \to 0.7$). Our findings reflect sequential streams on MS~MARCO; high-concurrency environments should combine SPHP with prefill admission control and speculation throttling. All software artifacts, traces, and scripts are open-sourced at \url{https://github.com/ApatheticMioz/geo-distributed-hybrid-rag}.

\section{Conclusion}
\label{sec:conclusion}
This paper presented an empirical measurement study of stage placement for hybrid RAG across geo-distributed edge--cloud tiers. We demonstrated that KV-cache state dominates latency variance ($2.8$--$3.2\times$) while TTFT is flat across WAN delays ($\approx$0.95~ms/ms) due to identifier-sized boundaries. Exploiting this retrieval-prefill asymmetry, SPHP overlaps masked cloud prefill with in-flight edge retrieval, cutting cold TTFT by 17\%--28\% ($h=0.900$, $p \le 0.0008$) without generative divergence and flattening Link~B sensitivity to $0.153$~ms/ms. Our analytical cost model proves global optimality for speculative split placement, corroborated by multi-tier physical experiments (CM-2), unshaped public WAN routes (CM-4), and multi-leg stress topologies (CM-5).
